# Assets

Esta pasta guarda os arquivos visuais e sonoros do jogo.

No MVP atual, o jogo usa formas simples geradas por código dentro do Phaser.

Estrutura futura sugerida:

```text
assets/
  sprites/
    player/
    enemies/
    bosses/
  backgrounds/
  tilesets/
  audio/
    music/
    sfx/
  ui/
```

Regras importantes:

- usar apenas assets próprios, comprados com licença válida ou gratuitos com licença clara;
- não usar personagens, símbolos, músicas, vozes ou efeitos sonoros de animes existentes;
- manter uma documentação de licença para cada asset real adicionado ao projeto.
